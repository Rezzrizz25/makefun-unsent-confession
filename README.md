A micro-confession in exactly two parts — a `To:` line and the one line that
was typed and never sent — for
[Unsent: The Micro-Confession Sprint](https://make.fun/bounty/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba)
on [make.fun](https://make.fun).

## The entry

> To: Lena
>
> i still wear the sweater you left at my place because returning it would mean admitting you're never coming back for it

## Run

Requires Node 22.18+ (the grader runs Node 22.23.4):

```sh
node main.ts
```

It writes the confession to `/output/entry.txt` — UTF-8 text of 1–260
characters, exactly two lines, the message line at most 200 characters.
